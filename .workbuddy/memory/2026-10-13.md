- `run-gui.cmd` 直接跑在沙箱里会被 SIGTERM（`start` 分离进程受限），改用分步启动：

## Veyra (Electron 版) 全量代码审查 + 修复

对 `D:/veyra-latest/src`（Electron + React，约 1.1 万行）做了完整审查，修复了 20+ 处 bug 与问题，全部通过 tsc / vite build / node --check / 真实 GUI 冒烟验证。

### 主进程（electron/main.cjs 等）
- `traffic:now` 误调用 SSE 端点 `/traffic`（永久挂起/4s 浪费）→ 直接读 `/connections`
- `updateCoreBinary` 先删二进制再下载（失败=内核丢失）→ 备份 `.bak` + 回滚 + 占用检测重试；打包后脚本路径/cwd/输出目录修复（`VEYRA_BIN_DIR` + `extraResources: scripts` + `ELECTRON_RUN_AS_NODE`）
- `windowBounds` 拖动时每帧写 settings.json → 400ms debounce
- `clearOurSystemProxy` 可能误关其它代理软件 → 按自有端口集合判定（`isOurProxyServer`）
- `settings:applyNetwork` 收养内核场景不重启 → `!!coreProc || !!coreOnline`
- 托盘「代理模式」子菜单无勾选 → 新增 `coreMode` 设置缓存 + `setCoreMode()` 统一入口
- `coreVersionInfo` 同步 execFileSync 阻塞 → 按 mtime + 60s TTL 缓存
- `proxy:delay` 超时抛异常刷屏 → 返回结构化 `{delay:0}`
- 死代码清理：`buildTrayProxySubmenu` 的 tpl、`window-all-closed` 的 preventDefault、verge-ext 未使用的 serviceMode 三函数、preload 的 `onTrafficWs`
- `clash2singbox.cjs`：`IP-CIDR,x,no-resolve` 无策略规则解析错误（生成非法 `ip_cidr:[""]` → sing-box 起不来）→ 先剥离 no-resolve 再解析

- 顶栏搜索框是死控件 → 接通到 query + 自动切代理页
- 首页系统信息卡硬编码假数据（开机自启/版本/OS）→ 真实数据；「节点」下拉从 disabled 装饰改为可切换节点

- Monaco 懒加载：主 chunk 4.49MB → 392KB（gzip 1.18MB → 122KB）
- `index.html` 移除阻塞渲染的 Google Fonts 外链；`main.tsx` 主题改为读 localStorage 缓存（消除浅色用户启动闪深色）
